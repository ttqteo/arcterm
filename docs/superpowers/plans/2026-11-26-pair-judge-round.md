Spec "Going back to the worker ends the round", "The token cap counts only the judge", "Who sleeps", "A judge that cannot sleep yet", and the planning decisions.
- `Side` gets `Launched bool \`json:"launched,omitempty"\`` beside `Briefed`. `Start` copies `d.Launched` onto the judge's side.
- `takeAnswer`: on a stopped pair (any stop reason, token cap included), a worker reply that answers a message (`answeredBy` names one) is recorded and queued as today, and it does not resume the pair. A worker reply that answers nothing ends the round: mark it seen, do not record it, set the pair ended, and add the system line "Round ended: you went back to the working agent". After the change, tell the worker about the held commands it may run (pull Unpair's tell-the-worker step into one helper that both Unpair and this path call), then put the launched judges to sleep. A relaying pair keeps today's behaviour. Remove the old "a new worker answer resumes a stopped pair" path.
- Sleep: add `Sleep(ctx, tab) error` to `Link` (sleep now, no compaction). wavesrv's `livePairLink.Sleep` resolves the roster row, applies `sleepRefusal` and calls `sleepAgent(ctx, row, false)`. It ignores the auto-sleep setting. `sleepAgent` returns `(rtn, nil)` with `rtn.Background` set when background work stopped the sleep and nothing slept: `Sleep` turns that into an error naming the work, so the refusal is never read as a sleep. At the round's end, each live launched judge sleeps at once if it is idle and is skipped if it is asleep. If it is working or asking, the Manager adds it to an in-memory `sleepOnIdle` set. `TurnEnded` checks that set first, before its early return for a tab in no pair (a resting judge is in none): for a tab in the set it sleeps the judge and drops it from the set. `notePairStatus` passes an idle on when the tab is paired or in that set (add a Manager method such as `Watches(tab)`). A failed or refused sleep is logged, never swallowed.
- Resting index (`rest.go`): the first load reads every pair file (replace `loadActive` with a read of all files that the index splits into active and ended). Resting means: per launched judge tab, the pair with the newest `CreatedTs` has ended. Keep it up to date in `change` when a pair ends, and in `Start` when a judge joins. `Manager.Resting() []wshrpc.PairResting`, and `PairListCommand` fills `Resting` from it.
- `settle`: `p.Tokens` sums the judges only, gone judges included. The worker's `Side.Tokens` is still read and stored. A new `Pair.JudgeTokens bool \`json:"judgetokens,omitempty"\`` says `Tokens` counts the judges only: `Start` sets it on a new pair, and `settle` sets it the first time it recounts an active pair. The server's Paused line becomes "Paused: judge token cap reached (3.0M)". `document.go`'s header line says "… of 3.0M judge tokens" only when `JudgeTokens` is set, and "… of 3.0M tokens" for an older pair, whose saved count includes the worker. A stored ended pair is never recounted.
- `docs/guide/agent-pair.md`: the round, how it ends (any new worker turn on a stopped pair that answers no message), the token cap counting the judge only, and the resting judge that Add judge wakes. Replace the rule "a new worker answer resumes every stop except the token cap". CHANGELOG `Changed`: one user-facing line for the whole feature (the judge is a line in the worker's row, going back to the worker ends the round and the judge sleeps until the next one, the cap counts judge tokens).
- Acceptance (`go test ./pkg/agentpair -run '<the names you add>'`, and `go test ./pkg/wshrpc/wshserver -run 'Pair'`, with the CGO prefix on Windows):
  - a worker turn on a stopped no-new-points pair, and one on a token-cap pair, that answers nothing ends the pair, adds the round line, is not recorded, sleeps an idle launched judge, does not sleep a picked (not launched) judge, and moves no judge into a queue;
  - a worker reply to a message the judge sent before the stop is recorded and queued, and the pair stays stopped;

  - a launched judge that is working at the round's end sleeps at its next `TurnEnded`, not before;
  - `Resting()` lists a launched judge whose newest pair ended, drops it when it joins a new pair, and survives a reload from files;
