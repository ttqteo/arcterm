# Job queue Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make every heavy job on the machine (agents' builds, typechecks and whole test suites; the engine's
Verify, Check and Final) take turns in one queue, a set number at a time (1 by default), with a footer button
that shows the queue and lets the person move a job to the front, remove it, stop it, and change the slots.

**Architecture:** `pkg/jobqueue` holds the queue in wavesrv's memory. Agents enter through the Claude mod's and
the pi extension's shell hooks, which run `wsh jobs hold -- <command>` (a streaming RPC whose lease lives as
long as the `hold` process); engine stages enter in-process in `pkg/orchestrate`. A `jobqueue` event carries the
whole queue to a footer chip and popover. Underneath, a dead `wsh` now ends its request contexts, which today it
does not.

**Tech Stack:** Go (wavesrv, wshrpc, gopsutil, `task generate`), the Claude Code mod API, pi extensions,
React 19 + jotai + Tailwind 4, vitest, CDP scenarios.

**Spec:** `docs/superpowers/specs/2026-10-08-job-queue-design.md`. Read it first; this plan does not repeat its
rationale.

### Task 2: `pkg/jobqueue`: the queue

**Depends on:** none
**Files:** `pkg/jobqueue/jobqueue.go`, `pkg/jobqueue/jobqueue_test.go` (both new)

Pure Go, no processes: the queue, its slots, Front/Remove/Stop, the nested rule, and reaping a lease whose
agent is gone.

**Step 1: Write the failing tests** (`pkg/jobqueue/jobqueue_test.go`). Cover, each as its own test:

1. FIFO with one slot: A granted at once; B and C wait; releasing A grants B, then C.
2. Progress: B's `progress` gets position 1 with A as `ahead`; C gets 2, then 1 when A releases.
3. Slots up: with A running and B, C waiting, `SetSlots(2)` grants B at once; `SetSlots(1)` with A and B running
   stops neither and grants C only after both release. `SetSlots(0)` and `SetSlots(9)` clamp to 1 and 4.
4. Front: A running, B, C waiting; `Front(C)` makes C next.
5. Remove: `Remove(B)` makes B's `Wait` return `ErrRemoved`; removing a running or unknown id errors.
6. Stop: `Stop(A)` ends A's returned context with `context.Cause == ErrStopped`, grants B without waiting for A's
   release, calls `Kill` with A's lease when A has a root and not when it has none; A's later release is a no-op.
7. ctx end while waiting: `Wait` returns `ctx.Err()` and the job leaves the queue.
8. Nested: A has `Root{Pid: 10, CreateMs: 100}`, granted at 1000. A request whose `Chain` is
   `[{20, 1500}, {10, 100}]` is nested (granted at once, `Nested`, no slot used); one whose `Chain` is
   `[{10, 100}]` (a parallel call of the same agent) waits; one whose chain is `[{20, 900}, {10, 100}]` (started
   before the grant) waits; an engine lease (no root) never parents.
9. Reap: `Reap(alive)` with `alive` false for A's root releases A (granting B) and makes a waiting job with a dead
   root return `ErrAgentGone`; leases without a root are never reaped.
10. `OnChange` gets a snapshot after every change, running then waiting in order, with `Slots`.

Use `q := New(1)` with `q.now` stubbed to a counter, and `Wait` in goroutines with a `granted` channel per job.
Example for (1):

```go
func waitAsync(q *Queue, ctx context.Context, req Request) (<-chan func(), <-chan error) {
	granted := make(chan func(), 1)
	failed := make(chan error, 1)
	go func() {
		_, release, err := q.Wait(ctx, req, nil)
		if err != nil {
			failed <- err
			return
		}
		granted <- release
	}()
	return granted, failed
}

func TestOneSlotIsFirstInFirstOut(t *testing.T) {
	q := New(1)
	ctx := context.Background()
	a, _ := waitAsync(q, ctx, Request{Job: "a"})
	relA := <-a
	b, _ := waitAsync(q, ctx, Request{Job: "b"})
	waitFor(t, func() bool { return len(q.Snapshot().Waiting) == 1 })
	c, _ := waitAsync(q, ctx, Request{Job: "c"})
	waitFor(t, func() bool { return len(q.Snapshot().Waiting) == 2 })
	select {
	case <-b:
		t.Fatal("b ran beside a")
	case <-time.After(50 * time.Millisecond):
	}
	relA()
	relB := <-b
	relB()
	(<-c)()
}
```

(`waitFor` polls a condition for up to a second.)

**Step 3: Implement** `pkg/jobqueue/jobqueue.go`:

```go
// Copyright 2026, Command Line Inc.
// SPDX-License-Identifier: Apache-2.0

// Package jobqueue makes the machine's heavy jobs take turns: agents' builds, typechecks and whole test suites
// (through `wsh jobs hold`) and the engine's Verify, Check and Final, a set number at a time. It is wavesrv's, in
// memory: a restart drops it, and the hold processes waiting in it let their commands run.
package jobqueue

const (
	MinSlots     = 1
	MaxSlots     = 4
	StateWaiting = "waiting"
	StateRunning = "running"
)

var (
	ErrRemoved   = errors.New("removed from the job queue by the person")
	ErrStopped   = errors.New("stopped from the job queue by the person")
	ErrAgentGone = errors.New("the agent that queued it is gone")
)

// Proc names a process across PID reuse.
type Proc struct {
	Pid      int32
	CreateMs int64
}

// Owner is whose job it is: an agent's block oref, or an engine stage's run, task and label.
type Owner struct {
	ORef      string
	RunID     string
	ChannelID string
	TaskID    string
	Label     string
}

// Request is one heavy job asking for a turn. Root is the agent process whose command it is (the hold's parent)
// and Chain the hold's ancestors, nearest first; both are zero for an engine stage. Hold is the hold process,
// which Stop spares.
type Request struct {
	Job   string
	Owner Owner
	Root  Proc
	Hold  Proc
	Chain []Proc
}

type Lease struct {
	ID string
	Request
	State     string
	Nested    bool
	QueuedMs  int64
	GrantedMs int64
}

type Snapshot struct {
	Slots   int
	Running []Lease
	Waiting []Lease
}

type entry struct {
	lease   Lease
	ctx     context.Context
	runCtx  context.Context
	cancel  context.CancelCauseFunc
	granted chan struct{}
	ended   chan error
	done    bool // released, stopped or reaped: release is a no-op
}

type Queue struct {
	mu      sync.Mutex
	slots   int
	running []*entry
	waiting []*entry
	seq     int
	tick    chan struct{} // closed and replaced at every change, so waiters re-read their position
	now     func() time.Time
	// OnChange gets the whole queue after every change, outside the lock.
	OnChange func(Snapshot)
	// Kill ends what a stopped agent lease's command started; nil kills nothing.
	Kill func(Lease)
}

func New(slots int) *Queue {
	return &Queue{slots: ClampSlots(slots), tick: make(chan struct{}), now: time.Now}
}

// Default is wavesrv's queue; main-server sets its slots, OnChange and Kill.
var Default = New(MinSlots)

func ClampSlots(n int) int { return min(max(n, MinSlots), MaxSlots) }
```

Then the methods, each taking `q.mu`, ending in `q.changedLocked()` (which closes and replaces `tick` and returns
the snapshot) and calling `OnChange` after unlocking:

- `Wait(ctx, req, progress func(pos int, ahead Lease)) (context.Context, func(), error)`: builds the entry
  (`ID` `job-<seq>`, `QueuedMs`), grants it at once as `Nested` when `parentLocked(req)` finds a running lease it
  is a child of, else appends it to `waiting` and runs `pumpLocked`. Then loops on `select` over `e.granted`,
  `e.ended`, `ctx.Done()` and the current `tick`; on a tick it reads its position (1-based) and the lease ahead,
  and calls `progress` when the position changed. Granted: returns `e.runCtx` and a `sync.Once` release that
  removes the entry from `running` (if still there), cancels `runCtx` and pumps. `ctx.Done()`: removes the entry
  from `waiting`, pumps, returns `ctx.Err()`.
- `grantLocked(e)`: `State` running, `GrantedMs`, `runCtx, cancel = context.WithCancelCause(e.ctx)`, appends to
  `running`, closes `granted`.
- `pumpLocked()`: while the non-nested running count is under `slots` and someone waits, grant `waiting[0]`.
- `parentLocked(req)`: the first running entry with a non-zero `Root` for which `childOf(req.Chain, lease)`.
- `childOf(chain []Proc, l Lease) bool`: finds `l.Root` in `chain` (pid and create time both match); true when
  some entry before it has `CreateMs >= l.GrantedMs`.
- `SetSlots(n)`: clamps, pumps.
- `Front(id)`: moves a waiting entry to index 0; an id not waiting is an error.
- `Remove(id)`: drops a waiting entry and sends `ErrRemoved` on its `ended`; an id not waiting is an error.
- `Stop(id)`: a running entry: marks it done, drops it from `running`, `cancel(ErrStopped)`, pumps; after
  unlocking calls `Kill(lease)` when `Kill != nil` and the lease has a root. An id not running is an error.
- `Reap(alive func(Proc) bool)`: every entry with a non-zero root that `alive` says is gone: a running one is
  released (cancel cause `ErrAgentGone`), a waiting one gets `ErrAgentGone` on `ended`.
- `Snapshot()`: copies of the leases, running then waiting, and `Slots`.

**Step 4: Run them to see them pass:** `go test -race ./pkg/jobqueue`. Expected: PASS.

**Step 5: Commit** `feat(jobqueue): heavy jobs take turns, a set number at a time`.

### Task 5: `wsh jobs hold` and `wsh jobs list`

**Depends on:** Task 4
**Files:** `cmd/wsh/cmd/wshcmd-jobs.go`, `cmd/wsh/cmd/wshcmd-jobs_test.go` (both new)

The hook protocol is one JSON line per line on stdout, compatible with memgate's: `{"hold":"..."}` while
waiting, then one of `{"granted":true}` (the turn starts; `hold` stays until it is killed, its stream ends, or —
with `--watch-stdin` — its stdin closes), `{"run":true}` (no turn needed: light, or a dev server),
`{"run":false,"reason":"..."}` (removed). After a grant, a stop prints `{"stopped":"..."}` and exits. Any error
exits nonzero with nothing on stdout, and the hooks let the command run.

**Step 1: Write the failing tests** (`wshcmd-jobs_test.go`, in the style of `wshcmd-memgate-decide_test.go`):

1. A light command (`ls -la`) and `task dev` print `{"run":true}` without connecting (`RpcClient = nil`,
   `WAVETERM_JWT` empty).
2. `holdLines` (the pure part) turns a message stream into lines: `[{Position:2, Ahead:"final-verify"},
   {Position:1, Ahead:"final-verify"}, {Granted:true}]` gives two `hold` lines ("waiting: 2nd in the job queue,

```go
// engineJobs is the queue engine stages take turns in: a var so a test can give the engine its own.
var engineJobs = func() *jobqueue.Queue { return jobqueue.Default }

// stageJob names a stage's job as memgate names its command, or by the stage when memgate does not know it.
func stageJob(command, stage string) string {
	if job, ok := memgate.Classify(command); ok {
		return job.Name
	}
	return stage
}

// stageLabel is the owner the job queue shows for a stage: the run's goal and the task.
func stageLabel(goal, taskID string) string {
	return goal + " · Task " + strings.TrimPrefix(taskID, "t-")
}

// waitTurn takes a turn in the job queue for a stage's commands. The context it returns ends with
// jobqueue.ErrStopped when the person stops the stage; release must be called.
func waitTurn(ctx context.Context, job string, owner jobqueue.Owner) (context.Context, func(), error) {
	return engineJobs().Wait(ctx, jobqueue.Request{Job: job, Owner: owner}, nil)
}

// queueEnded is the job queue's reason a stage ended — removed or stopped by the person — or nil.
func queueEnded(err error, ctx context.Context) error {
	for _, e := range []error{err, context.Cause(ctx)} {
		if errors.Is(e, jobqueue.ErrRemoved) || errors.Is(e, jobqueue.ErrStopped) {
			return e
		}
	}
	return nil
}
```
